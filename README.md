# 薬剤師シフト管理 PWA

薬局のシフト管理用ウェブアプリ。ブラウザに「アプリとしてインストール」可能。

## 機能
- 休み / 出勤 / 他店ヘルプ / 有給 を週単位で管理
- 早出・遅出・通し・半日 などのシフトパターンを時間モードで割り当て
- 公平性最優先の自動割り当て（前日ルールはタイブレーカー）
- ロック機能 + シャッフル + スナップショット保存
- ヘルプ要員の追加 (店舗カウントに +1)
- パート (週上限) と 正社員 (月所定) で目標時間管理
- オフライン動作 (Service Worker キャッシュ)

## 使い方
1. アプリを開いて、休みモードでセルクリック → 空 → 休 → 出 → ヘ → 有 → 空 と循環
2. 時間モードでパターン割り当て、🎲 自動割り当てで一括配分
3. 最終調整モードで個別の時間微調整 (15分単位)
4. 完成したら 📷 スナップショットで保存

## ファイル構成
- `shift.html` — アプリ本体 (HTML + CSS + JS 一体)
- `manifest.json` — PWA マニフェスト
- `service-worker.js` — オフライン用キャッシュ
- `icon-192.png` / `icon-512.png` / `icon.svg` — アプリアイコン

## ローカル開発
```bash
python3 -m http.server 8000
# → http://localhost:8000/shift.html
```

データは localStorage に保存。「エクスポート」ボタンで JSON バックアップ可。

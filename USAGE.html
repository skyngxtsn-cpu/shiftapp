📋 薬剤師シフト管理アプリ 使い方ガイド

https://skyngxtsn-cpu.github.io/shiftapp/shift.html
シフト作成者向け / 2026年版
このアプリでできること: 月度（16日〜翌15日）単位でシフトを組む。希望休の集約・不足日の検出・自動割り当て・時間調整・スナップショット保存まで一通り対応。データは端末ごとにブラウザ保存（オフライン動作）。

🗓 月度の基本

  • シフト周期: 16日〜翌15日（ヘッダの ◀ ▶ で月度切替）
  • 各月度のデータは独立して保存される
  • データはブラウザに自動保存（複数端末で使う時は「エクスポート」で JSON 持ち運び）
  • 初回使用時は ⚙ 設定 でメンバー名・パターン時刻・必要人数 を編集

🎛 3つのモード（ヘッダ中央のタブ）

① 休み決めモード（最初に使う）

セルクリックで状態が循環:

空 → 休 → 出 → ヘ → 有 → 空
状態意味人数カウント
空未設定（デフォルト出勤扱い）+1
休絶対休み（希望休）0
出絶対出勤（在宅・研修など休めない日）+1
ヘ他店ヘルプに行く（自店舗カウント外）−1
有有給休暇（時間カウント対象）0（労働時間にはカウント）

下部パネル3つ:

  • ① 不足日リスト（ヘルプ要請対象）
  • ② 週休チェック（週1日相当）
  • ③ 休みの提案（不足を埋める候補）

② 時間決めモード（休み確定後）

セルクリックでパターン選択（早番・通し・遅番・木曜早…）。

  • 🎲 自動割り当て: 公平性最優先で全員に早/遅/通しを配分
  • 各人の早出/遅出回数が均一になるよう動く
  • 遅番ペアもランダム化で同じペア連発を回避
  • 「遅出の翌日 → 早出」「休みの翌日 → 遅出」を可能な範囲で適用
  • ロック済みセルは触らない
  • 🕐 時間を直接編集: 各セルのポップオーバーから、パターンの時間だけ15分刻みで上書き可

③ 最終調整モード

セルに 開始-終了時刻 を表示。クリックで個別に時間調整。

  • パターンから変えた時間は 赤字 で表示
  • 「パターン通りに戻す」ボタンで元に戻る
  • ロック済みセルもクリックで時間「閲覧」可能（編集はできない）

🔘 ヘッダのボタン

ボタン用途
🔒 ロック編集ON にしてセルクリック → ロック切替（金色枠 + 🔒）。ロック中のセルは自動割り当てで触られない
📷 スナップショット現在の周期の状態を名前付きで保存。後で復元可
🗑 全クリア現在周期のシフトを全消去（二重確認あり）
⚙ 設定メンバー・パターン・自動割当ルール等の編集
エクスポート/インポートJSON でバックアップ・端末間移動

🔄 おすすめ運用フロー（月次）

■ 月初（前月20日まで）

  1. 各メンバーから希望休を集める
  2. アプリで月度を切替（▶ で次月度へ）
  3. 休みモードで希望休 →「休」、絶対出勤日 →「出」、有給 →「有」を入力
  4. 自分が他店ヘルプに行く日 →「ヘ」

■ ヘルプ調整

  1. 下部パネル①「不足日リスト」を確認
  2. ヘルプ要員（外部から来る人）→「ヘ+」で +1
  3. それでも足りない日はエリアマネージャーに依頼

■ 時間決定

  1. 時間モードに切替
  2. 🎲 自動割り当て で一発配分
  3. 不公平・違和感のある日を手動修正
  4. 確定した部分を 🔒 ロック → もう一度 🎲 で残りシャッフル

■ 最終調整

  1. 最終調整モードで個別の時間を 15分単位で微調整
  2. 完成したら 📷 スナップショット保存（名前: "5月度・確定版" 等）
  3. エクスポートで JSON もバックアップ

■ 月末

  1. 印刷 or スマホで各スタッフに共有
  2. 翌月度に切替（▶）→ サイクル繰り返し

⚙ 初期設定（最初の1回だけ）

設定 → 順に確認:

  • メンバー一覧: 名前を本物に変更（A/B/C/D/E/F → 実名）。種別（正社員/パート/ヘルプ）を設定。▲▼ で並べ替え
  • シフトパターン: 既定で 早番・通し・遅番・木曜系・土曜系・半日早/遅・有給・ヘルプ が登録済み。⋮⋮ ドラッグで並べ替え可。時刻は会社の実際の時間に合わせて編集
  • 曜日ごとの自動割当ルール: 各曜日に何人を早/遅/通しに配分するか。残りパターンは複数指定可
  • 曜日ごとの設定: 必要人数、休み価値、営業/閉局
  • 祝日: 「日本の祝日を自動取得」ボタンで一括取込
  • パート週上限: デフォルト32時間

🎯 公平性ロジック（自動割り当ての中身）

何を均一化しているか

各メンバーごとに 3種類のカウント を周期内で集計:

カウント意味
earlyRole「早出役パターン」を担当した回数（全曜日合算）
lateRole「遅出役パターン」を担当した回数（全曜日合算）
fill[pattern]各「残りパターン」を担当した回数

スコア式（小さいほど選ばれやすい）

早出選定 (各日 1人):
  score = earlyRole × 100 + (前日が遅出役 ? -10 : 0) + Math.random()

遅出選定 (1人ピック):
  score = lateRole × 100 + (前日が休み/閉局/祝日 ? -10 : 0) + Math.random()

遅出ペア選定 (2人ペア):
  score = (lateRoleA + lateRoleB) × 1000
        + pairCount[a,b] × 30
        + (前日休みボーナス: -10 each)
        + Math.random() × 10

残り (fill) 選定:
  score = fill[patternId] + Math.random() × 0.5

優先順位の設計

桁何を優先
×1000 / ×100公平性カウント（最優先）
×30ペア多様化（遅出のみ）
×10 / −10前日ルール（タイブレーカー）
×0〜1ランダム（同点最終ブレイク）

→ 公平性が圧倒的に優先、それを満たす範囲でルールが効く設計

「無理なら無理」の柔軟性

ハード制約（必須）:

  • 休 / 他店ヘルプ のセルは絶対に上書きしない
  • ロック済みセルは触らない
  • 必要人数を超えて配分しない

ソフト制約（できる範囲で）:

  • 公平性: cnt 差 1 以下を目指す（avail が少ない日は妥協）
  • 遅→翌日早: 翌日 avail に該当者がいなければスキップ
  • 休→翌日遅: 同上

制約を満たせない日は「出（時間未定）」のまま残し、ユーザーが手動で調整。

💡 Tips

  • 複数のシナリオを比較したい時: 案ごとに 📷 スナップショット → 復元で切替
  • 公平性が崩れてる気がする時: 🎲 を何度か押す（毎回少し変わる）
  • 特定の組み合わせを固定したい時: その日のセルを 🔒 ロックしてから 🎲
  • JSON エクスポートのタイミング: 月の確定時 + 大きな変更前
  • データが消えた: インポートで JSON 復元、または スナップショットから復元
  • アプリが重い・古い: ブラウザリロード or アンインストール → 再インストール（データはローカルに残る）

🆘 困った時

問題対処
不足日に出てるけど誰にも頼めないその日の必要人数を一時的に減らす（曜日設定 → 必要人数）
自動割当が想定と違う配分自動割当ルール表で 早出/遅出 の数や残りパターンを調整 → 再実行
特定の人に偏りすぎ全体を 🗑 全クリアして 🎲 やり直し（既存ロックも一緒に消える点注意）
複数月で同じ設定を使いたい設定はアプリ全体で共有（周期切替で持ち越される）

📊 結果のチェック方法

グリッド右端の「早/遅」列で各人の合計が表示される:

A: 早3 / 遅2
B: 早2 / 遅3
C: 早3 / 遅2
D: 早2 / 遅3
E: 早3 / 遅2
F: 早2 / 遅3

→ 各人の早+遅 = ほぼ同じ、早/遅の差も ±1 以内なら公平に配分されている。
